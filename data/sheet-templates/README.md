# McLink portal sheet templates

These header-only CSV files are templates for the live Google Sheets workbook.
They do not modify or replace the existing `ELLA_ HR Resume Screener.xlsx` file.

Create one tab per CSV file and preserve the header spelling exactly. The portal
uses `Role_ID` as the link between requisitions and candidate-processing sheets.

Required tabs:

- `Role_Requests.csv`
- `Role_Status_History.csv`
- `User_Directory.csv`
- `Settings.csv`
- `Role_AI_Settings.csv`
- `Recruitment_Templates.csv`
